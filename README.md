# YouTube AI Topic Radar

一个面向 AI 视频创作者的多语言 YouTube 话题雷达 Codex Skill。

它持续观察 53 位英语、法语、德语和西班牙语 AI 创作者，并补充追踪 4 个公开的大学研究与产品更新来源，把近期视频整理为可追溯的国际前沿 AI 趋势、跨语言差异和原创视频选题参考。报告用中文写，选题以全球 AI 发展和产品应用为中心。

> This Codex skill monitors multilingual YouTube AI creators and turns recent, source-linked activity into original video-planning references.

## 它解决什么问题

AI 资讯更新很快，但逐个查看几十个频道会花费大量时间，而且容易只看到英语内容。这个 Skill 将分散的视频更新转化为一份结构化研究结果：

- 哪些 AI 话题最近被多个创作者同时关注；
- 英语、法语、德语和西班牙语创作者的关注角度有何不同；
- 哪些话题只是单一频道的早期信号，哪些已经形成跨频道趋势；
- Meta AI/Llama、Gemini、Grok、即梦/Jimeng 等产品，以及当期新出现的模型、工具或研究，哪些真的被名单内创作者讨论；
- 某个重要产品如果没有出现在本期名单中，是监测盲区还是已有可核验的创作者信号；
- 如何在不复制他人标题、脚本或缩略图的情况下，形成自己的视频方案。

## 具体可以应用什么

| 应用场景 | 可以完成的工作 | 主要输出 |
|---|---|---|
| 双周国际 AI 趋势追踪 | 扫描监测窗口内 53 个频道的新视频，合并重复链接并聚类前沿模型、智能体、AI 科研、多模态、开源与安全等主题 | 中文趋势摘要、热门话题排行、来源链接 |
| 原创视频选题 | 根据近期信号提出适合制作的内容方向，并评估时效性、受众价值和制作可行性 | 5–10 个选题、目标受众、原创角度、选题评分 |
| 标题与开场策划 | 把趋势转化为自己的标题方向、开场钩子、视频结构和演示方式 | 中文工作标题、Hook、内容格式、需要准备的证据或 Demo |
| 跨语言内容研究 | 比较英语、法语、德语和西班牙语创作者对同一项国际 AI 进展的不同解释和测试 | 跨语言差异、观点与证据缺口 |
| 全球 AI 产品观察 | 跟进 Meta AI/Llama、Gemini、Grok、即梦/Jimeng 等实际出现在监测视频中的产品，也记录重要产品的本期覆盖缺口 | 独立创作者数、视频来源、官方核验链接、未覆盖标记 |
| 大学研究与产品更新补充观察 | 从 Harvard Gazette 的 AI 研究与社会议题，以及 Neon、Apify、Artlist 的公开更新中筛选有实质内容的条目 | 单列的补充来源清单、原文链接、发布日期和待核验问题 |
| 竞品与频道观察 | 查看每位创作者近期活跃度、主要主题和代表性视频 | 创作者活动表、频道状态、内容定位参考 |
| 内容栏目规划 | 从连续多期报告中识别适合教程、测评、新闻、访谈或案例拆解的稳定栏目 | 栏目方向、内容形式、后续观察清单 |
| 结构化研究归档 | 将视频、主题标签、语言和选题结果保存为机器可读数据 | Markdown 报告和 JSON 数据集 |

适合关注国际 AI 前沿的工具测评博主、AI 教育者、开发者、视频创作者和多语言内容团队。

完整频道与主题标签见 [`references/creator-roster.md`](references/creator-roster.md)。名单并非单纯按订阅量排名，而是综合考虑 AI 相关度、近期活跃度、国际前沿话题覆盖、内容质量和创作参考价值。产品示例只是观察线索；每期都按真实视频和官方资料更新，不预设品牌必须上榜。

另外追踪 4 个**公开资料来源**，详情见 [`references/newsletter-watchlist.md`](references/newsletter-watchlist.md)：

| 来源 | 用于观察什么 | 筛选边界 |
|---|---|---|
| Harvard Gazette | 大学发布的 AI 科研、教育、政策与社会影响文章 | 每篇判断是否与 AI 相关；普通校园新闻和课程促销不收录 |
| Neon Changelog | AI 开发基础设施、模型访问、智能体相关产品变更 | 只记录有日期且可核验的更新 |
| Apify Changelog | AI Agent、网页数据与自动化工具变更 | 只记录有日期且可核验的更新 |
| Artlist Blog | AI 视频、图像、音频和创作者工作流 | 排除空泛推广，保留有实质内容的文章 |

这些来源在报告中**单独列示**。大学报道和厂商公告可帮助发现值得继续调查的话题，但不计入 53 位 YouTube 创作者的视频数、独立博主数或跨频道热度。采集使用公开网页，不读取或公开私人邮箱内容。

## 三种使用模式

### 1. Refresh：刷新近期话题

扫描指定时间段内的频道更新，收集公开可验证的视频资料，形成最新趋势报告和数据集。

每条视频记录可包含：

- 创作者和主要语言；
- 原始标题和中文译名；
- 发布日期和视频链接；
- 可见播放量（能够取得时）；
- 长视频、Short、直播或播客等格式；
- 前沿模型、AI 科研、智能体、编程、创意生成、开源、机器人、安全等多标签分类，以及实际提到的产品或模型。

### 2. Video reference：生成视频参考方案

使用最新报告或指定时间段的研究结果，生成原创的视频策划，包括：

- 目标观众；
- 与已有视频不同的切入角度；
- 开场 Hook；
- 中文工作标题；
- 建议的视频形式和内容结构；
- 需要实际测试、演示或查证的部分；
- 灵感来源和需要避免的模仿风险。

### 3. Roster maintenance：维护监测名单

检查频道是否改名、停更、重复或改变方向，并提出替换或新增建议。当前 53 位名单的语言结构为 `23/10/10/10`，不会因为一次访问失败而自动删除频道。Dwarkesh Patel 和 Marketing Against the Grain 的非 AI 内容不计入话题统计。

## 如何判断值得做的话题

每个候选话题可按 25 分制评估：

- 时效性；
- 跨频道信号强度；
- 对目标受众的实际价值；
- 视频制作可行性；
- 原视频还没有讲清楚的机制、独立测试、限制或实际用法。

单一频道提出的新观点仍可进入观察清单，但会标记为早期信号，而不是跨频道趋势。某个产品在固定名单中没有视频，会标记为「本期名单未覆盖」，不能据此判断它在国际上不热门。完整规则见 [`references/report-format.md`](references/report-format.md)。

## 使用示例

安装后，可以直接在 Codex 中提出这些请求：

```text
使用 $youtube-ai-topic-radar 刷新过去 16 天的 53 个频道，并生成中文趋势报告。

同时查看 Harvard Gazette、Neon、Apify 和 Artlist 在同一时间段的公开 AI 更新，单独列出值得继续调查的研究和产品信号。

比较英语、法语、德语和西班牙语 AI 博主最近对 AI Agent 的关注差异。

根据最新报告，为 AI 工具测评频道提出 10 个原创选题，包含标题、Hook、视频形式和需要演示的内容。

找出最近两周被至少三个不同频道讨论的话题，并按创作机会评分。

Meta AI/Llama、Gemini、Grok、即梦/Jimeng 及本期新出现的产品，分别有多少独立创作者讨论？哪些只是监测盲区？

找出最近两周国际 AI 前沿最值得讲的模型、AI 科研、视频生成与智能体话题，给出来源和原创实测角度。

检查监测名单中是否有改名、停更或内容方向明显变化的频道，只提出建议，不要直接删除。
```

也可以限定受众和内容形式：

```text
只保留适合非技术职场用户的选题。

只分析 AI 视频生成、AI 营销和电商自动化相关内容。

把结果改成适合 8 分钟 YouTube 视频和 60 秒 Shorts 的两套方案。
```

## 定期刷新

Skill 本身定义了双周采集流程，但不会自行在后台运行。可以在 Codex 中为它创建每两周一次的自动任务。首次运行或没有可靠的上次刷新状态时，默认查看最近 16 天，以保留两天重叠，减少边界遗漏。

自动任务的请求示例：

```text
每两周使用 $youtube-ai-topic-radar 刷新全部 53 个频道和 4 个公开补充来源，重点追踪全球前沿 AI 进展和产品。分开统计博主视频与大学/厂商更新，保存报告，并向我汇报最值得制作的 5 个选题、重要产品覆盖缺口和无法访问的来源。
```

## 输出文件

保存刷新结果时，默认在 Skill 目录中生成：

```text
reports/YYYY-MM-DD.md  # 带日期的不可变快照
reports/latest.md      # 最新中文报告
data/latest.json       # 最新结构化数据
```

Markdown 报告适合人工阅读和视频策划；JSON 数据可继续用于表格、数据库、仪表盘或其他内容工作流。生成的报告和数据默认不会提交到 Git 仓库。

## 证据与创作边界

- 每个收录视频都应保留来源链接和发布日期。
- 频道无法访问时标记为 `unavailable`，不能因此判断它没有更新。
- 播放量、订阅量、赞助状态和发布频率属于动态数据，必须附观察时间，缺失时使用 `null`，不猜测。
- 创作者视频只能作为趋势信号，不能替代产品、价格、政策或技术事实的一手来源。
- 大学报道和厂商更新单独列示；厂商声明只证明其自行发布的内容，不代表独立评测结论。
- 邮箱订阅信息、邮件正文、收件地址和追踪链接不进入公开仓库或报告。
- 结果必须进行原创整合，不复制脚本、独特措辞、标题或缩略图构图。
- Skill 不会自动发布视频、评论、订阅频道、联系创作者或操作外部账号。
- 只使用公开信息，不绕过登录、付费墙或平台限制，也不保存完整视频脚本或字幕副本。
